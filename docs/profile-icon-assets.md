## 公開前の確認事項

提供ファイル内には、配布元URL、作者名、ライセンス、クレジット条件の記載がありませんでした。そのため、現時点では利用条件を推測していません。

GitHub公開や配布を行う前に、各素材について次を確認してください。

- 配布元と作者
- 商用利用の可否
- 改変・アプリへの同梱・再配布の可否
- クレジット表記の要否

確認後、この文書とREADMEへ出典・ライセンスを追記します。
